## 不改状态的三日流程证据

`npm run test -- tests/playthrough.test.ts --reporter=verbose --silent=false` 实际通过 2/2。该文件不直接写入状态，不调用调试伤害或强制失效，不添加资源，不合成日快照，不修改工作耗时。

第一条流程从新档取得 44 累计产能，接受正常奶龙教学失效，用 4 名只持制式短棍的员工完成镇压并等待恢复；未购买技能或装备，没有重伤。镇压前后钱包均为 94、累计产能均为 44。

第二条流程从新档完成三日，正常工作获得资源，购买全部 10 页档案、5 组专属装备、5 个技能；实际穿戴 5 武器和 5 防具并施放全部 5 技能。通过真实互动工作造成奶龙失效、叮咚鸡失效与大狗联动失效，再下令镇压，最终进入完成状态。

总模拟时间为 **1102.45 秒，约 18.37 分钟（1 倍模拟时间）**。它是已知规则的脚本命令流程，不包含人类阅读、思考和界面操作时间，不构成“新人 15—25 分钟可通关”或难度平衡的证明。此路线有超额产能，不是三天刚好达标的最优消费路线。
