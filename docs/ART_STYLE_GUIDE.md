# 怪诞手绘收容风

本轮依据用户2026-10-20提供的《美术替换指南》实施。参考的是怪诞手绘语言；设施仍是本项目的地下工业剖面，不使用其他游戏的角色、脸型公式、界面、植被或贴图。

## 视觉语言

粗墨线、局部不对称轮廓、平涂、少量排线阴影；灰褐、灰蓝、脏绿与旧纸黄构成设施，铁锈红用于局部设备。背景对比度低于员工与收容物。外轮廓约3px，结构线约2px，面部和刻线约1px，均以世界坐标计。

信息优先级：实际危险 → 异常实体 → 员工状态 → 房间用途 → 装饰。危险用红/橙红；恐慌用紫；选择用浅黄；路径和恢复用浅青。色彩不能成为唯一线索，必须同时有形状、姿态或文字。

## 角色与设施

员工维持约66世界像素、大头小身、细长四肢、前倾姿态与独立发型。制服保持一个色系，装备只在武器轮廓和少量衣饰上区分。正常、工作、恐慌、受伤和重伤倒地的姿态须可分辨，不能只闪颜色。

五物保持各自的形状记忆点；平静和失控的差异体现在嘴、眼、四肢与身体轮廓，不能只给同一造型涂红。具体规则见[收容物规则](ABNORMALITY_VISUAL_RULES.md)。

房间边界、地板、门和连接位置保持实际几何；设备可略歪，通道不能靠透视错觉改变宽度。控制室以CRT控制台、医疗室以药柜和床、档案区以文件架、广播区以喇叭识别，避免靠大标题充当设备。

## 实现与暂停

本项目沿用Phaser。2026-10-21起默认设施采用`public/art/generated/`中的生成PNG拆件，由`src/art/generated/`内的骨架和模块接入。`src/art/ink.ts`继续负责精确范围、选中圈、路径与缺图回退；固定种子避免移动时重新随机。形状变化、呼吸、动作、墨迹消散及故障残影只读取模拟时间或实际状态；暂停时必须冻结。所有素材随本地工程加载，没有运行时外部素材请求。

这是一套生成后按实际游戏骨架组装的概念美术，不声称手工原画或官方角色还原。模型生成定稿与单姿态参考不是实机截图，也不直接驱动伤害或收入。`?slice=1`保留旧程序绘制回归入口，默认多层设施与正式三日共用新素材。原图、裁切尺寸和命名覆盖见`art-production/production-index.json`。
