# 卡牌可靠性与20秒战斗｜2026-10-23

按用户新目标将对应装备战斗调整为尽量20模拟秒内，覆盖旧补丁60–120秒目标。本轮保留原存档、经典模式、美术与其他未提交改动。

## 修复

1. 场内敌人点击检测原先先于员工；实体重叠时治疗牌误选敌人，导致无法出牌。现在根据当前卡牌目标类型优先选择友方，并支持右侧人员名单。
2. 复制牌原目标死亡时，原先看似可用但任何存活目标都不合法。现在正确禁用并说明应先对活目标使用攻击牌。
3. 移动目标跨出射程时原先重置前摇，短射程牌可能反复接近/准备。现在追踪期间保留前摇，仍必须实际进入射程才生效；暂停冻结不变。
4. 集火改令原先清除预备牌施放者的动作，现在保留预备牌与动作同步；目标死亡、员工恐慌/重伤取消有明确日志，不扣牌/不启动公共冷却。
5. 手牌上方显示施牌员工、牌名、接近/前摇/暂停预备状态，选牌提示友方或敌方，减少无反馈等待。

## 边界

20秒是对应装备满状态基准，不保证受伤队伍、主动撤退或无效出牌仍20秒；卡牌占用员工动作，也不是每张牌都增加输出。后三物全阶级尚未浏览器逐一通关。进行中的旧战斗保留原快照血量，新数值从新开战斗使用；刷新未完成战斗仍按放弃处理。
