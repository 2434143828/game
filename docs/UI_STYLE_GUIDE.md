# 旧网络收容档案界面

## 构成

保留顶栏资源、右侧人员/详情、底部技能的现有游戏布局和设施占比。视觉采用暗终端底、旧纸标签、墨色边框、少量铁锈印记；内容按现代网格对齐。不要使用其他游戏的面板轮廓，也不把全界面做成野外生存纸张菜单。

顶栏显示真实日期、累计产能、可用能量、模拟时钟和暂停。人员卡显示真实HP/SP、状态和选择；装备在装备分配面板查看。图标与文字同在。警报只显示实际失效、恐慌、重伤或压力危险，无事故时不伪造告警。

档案模板由打印编号、页签、记录区、规则注释和解锁区组成。手写/盖章感只作为结构点缀，价格、解锁条件与效果必须直接来自现有配置；不能用假监控数值装饰界面。

## 交互和可读性

- 1600×900与1280×720均保留原操作区域，不依赖网页滚动访问主游戏。
- 正文使用可读的系统中文字体，终端标签采用等宽字，手写风仅限短标题或批注。
- 选中用浅黄，恢复/路径用浅青，危险红，恐慌紫；同时附状态文字或图形。
- 面板保持近不透明，避免设施背景穿透文字。失效条不覆盖小人和范围预警。
- 原`data-action`、`data-employee`等入口保留；节流刷新真实内容和状态、按差异更新，不销毁/重建正在点击的按钮。
- 不用现实时间CSS动画驱动与模拟有关的警报、角色或技能效果。纯悬停反馈可以即时响应。

SVG图标是本项目可编辑的原创界面资源，不是员工场内实体的替代。真实员工、异常、工作与战斗继续由Phaser绘制。
