# 《网梗收容：奶龙失效》游戏流程书｜v0.4

版本：v0.4 主线流程优化
更新：2026-10-24
适用入口：默认 `/`；旧 `?mode=campaign`、`?classic=1`、`?slice=1` 仅兼容冒烟

本版本沿用 Phaser 2D 设施剖面、固定步模拟和单一状态树。设施空间、员工、异常实体、移动、普攻、卡牌和结算使用同一份运行状态。

## 本轮已实现

- 设施侧栏增加“下一目标”。它每次从房间拥有状态、阶级、能量和前置条件推导，只能聚焦真实房间，不能远程完成目标。
- 战斗结束在当前场景上方显示结算卡，读取真实的等级变化、E/min 变化、E.G.O. 上限、装备奖励和下一目标。`rewardApplied` 保持单次结算，自动返回与手动返回共用 `finishEncounter()`。
- 外勤抓捕新增配置化 `CAPTURABLE` 阶段。主目标达到阈值后锁定为非致死生命，停止员工普攻并提示“启动收容装置”。员工必须真实走到目标附近，持续执行收容进度；挣扎命中、改令或超时会中断并回到可收容状态。
- 收容进度由同一份战斗状态驱动。中断后按 `config/gameplay-v3.json.capture.progressRetainFraction` 保留已完成进度，再次启动不会清零；启动装置时会取消该员工尚未消耗的 pending cast，避免施牌动作与收容倒计时并行结算。
- 设施安全区继续提供免费的 HP/SP 随模拟时间恢复，人员栏在未满状态下显示恢复中，避免战败后永久无法出战。
- 旧 v0.3 存档缺少捕获字段时在模拟入口补齐默认 `COMBAT`，存档 schema 对新字段保持 optional 兼容。
- 存档校验要求收容员工属于当前小队；`CAPTURING` 必须绑定操作员工，其他阶段不得绑定；进度不得超过配置上限，捕获阶段与主目标 `captureState` 必须一致。

## 正常操作链

1. 进入设施，查看右侧下一目标和房间条件。
2. 选择员工或框选员工，在走廊右键下达移动命令；暂停期间命令可以修改。
3. N01 主动失效：三名员工进入战斗区，自动普攻；卡牌在合法目标、射程和前摇满足后才产生效果。
4. 胜利后先显示结算卡，再自动返回设施；结果卡和日志读取同一场战斗的真实奖励。当前实现会在 `finishEncounter()` 将参战员工定位到各自安全位置并清理战斗状态，稳定收容物恢复产能；沿导航路径逐段撤退仍是后续空间优化项。
5. 外勤抓捕：目标 HP 降至配置阈值后进入 `CAPTURABLE`，点击启动收容装置；持有装置的员工移动到射程并完成进度，成功后才入库并发放 I 阶 E.G.O.。
6. 抓捕失败或刷新退出不发奖励、不退外勤费用；员工保留受伤状态，在设施中等待免费恢复。

## 配置与数据

`config/gameplay-v3.json.capture` 控制阈值、装置距离、进度时长、超时和中断后保留进度比例。当前样例阈值为各目标 20%，只作为可编辑平衡值。战斗仍使用 5 秒抽牌、2.5 秒全局公共冷却和固定模拟 tick。

`docs/v04-combat-stats.json` 保存同一 seed 下 N01/N02 的 A（自动）、B（随机合法出牌）、C（按蓄力和低精神优先控制/防御/治疗）记录，包含抽牌、施牌、打断、HP/SP 损失、自动攻击和卡牌贡献等字段。

统计基线：N01 A/B/C 约 14.4/16.5/16.6 秒，N02 A/B/C 约 11.4/11.6/11.4 秒；当前明显低于 v0.4 建议的 20–35 秒新手主动失效、35–60 秒后续抓捕/升阶区间，仍需实玩后平衡。
