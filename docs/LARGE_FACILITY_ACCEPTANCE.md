# 多层设施、镜头与空闲散步｜2026-10-20

本轮响应用户对设施过小、区域排列过整齐、员工缺少日常活动的反馈。此前五室单排及两人单室证据保留；本文件只记录新地图的实现和本轮实际验证。

## 已实现

- **一张真实的大地图**：3600×2500世界，五间尺寸不同的收容室、五个大厅、医疗休整区与三条竖向通路。房间分布在不同高度，连接关系有错位、支路和中间空腔。保持原五物，未加入自由建造。
- **镜头**：默认60%视野同时可见收容物和员工；滚轮缩放、中键/Alt拖动、Home总览、F/双击员工跟随、小地图定位和五室快捷定位。操作点、框选、角色、危险预警、技能目标使用同一投影。
- **日常活动**：无任务员工按固定模拟时间等待后散步，沿同一张通路图移动；玩家命令打断，STOP持续驻足，撤退员工完整恢复后才恢复散步，失效事故期间停止散步。不自动派工作或镇压。
- **实际路径**：员工与异常均沿图移动，跨层任务需要真实通勤。普通攻击和S03不穿楼板，击退留在当前连续水平走廊。叮咚鸡的全设施广播、全体加速、精神恢复的世界半径沿用原规则。
- **设施视觉**：浅色内墙与深色结构、不同色温及体量的大厅、实体侧门、观察窗、设备、管线与竖向连接。角色仍有分部件动作，五种收容物保持独立轮廓。

对照了[《脑叶公司》官方商店实机图](https://store.steampowered.com/app/568220/Lobotomy_Corporation__Monster_Management_Simulation/)中的多层错落分布、大小房间对比、部门照明和暗色空间。游戏中的图形由程序绘制，未导入其贴图或角色资源；不把本Demo的五物内容量称作完整商业游戏的规模。
