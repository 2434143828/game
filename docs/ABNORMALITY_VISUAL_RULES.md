# 五种收容物的视觉规则

五物分别读取同一份真实房间/敌人状态。室内`working`只在员工抵达且作业为`EXECUTING`时出现；失控造型只由实际敌方实体触发。艺术变形不修改碰撞/目标位置、伤害、射程或数量。

| 收容物 | 平静/作业 | 失控记忆点 |
|---|---|---|
| 奶龙 | 软黄、短手、圆润身体；交互时探头或摆手 | 拉长轮廓、空眼和裂开的嘴；主样本与两个缩小分身保留 |
| 耄耋 | 灰色猫形、迟钝的异形眼、尖耳和毛簇 | 细长四肢、扭曲躯干、张开的表情与局部墨线震颤 |
| 大狗 | 大体量、钝重的背和口鼻，灰褐色块 | 夸张张口、前冲轮廓和影子；蓄力范围仍精确对应实际攻击 |
| 叮咚鸡 | 滑稽鸡冠、纸白躯干与钟铃识别点 | 广播嘴部/肢体张开、同一实体的错位残影与干扰线 |
| 咕咕嘎嘎 | 冷色企鹅轮廓、白肚与滑稽短足 | 冷色错帧、拉伸或重复描边、明显不对称表情 |

每种主要实色控制在三个色群内，黑墨线和小面积警报色不参与背景装饰。正常和失控须在缩略尺度仍可辨识；禁止只加红光而不改变造型。

受击墨点必须跟随真实HP/SP下降；受控姿态、攻击前摇和命中动作跟随真实时钟。残影不具备单独ID、可选区域或伤害，不误示为额外分身。美术没有改变原五物边界。

所有形象为本项目程序绘制的概念造型，不声称还原官方IP资源。用户未提供官方图片/配音，本轮不抓取相关素材。
