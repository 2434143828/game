# 决策登记｜v0.3补丁优先

2026-10-23外勤美术补丁：CAPTURE采用五物独立现实环境＋模因污染，按用户设定生成商场、社区、宠物公园、地铁广播、母婴角；不再复用实验室白墙。室内主动失效仍使用设施。第一版静态底景允许，污染/危险预警/实际角色继续绑定唯一模拟。奶龙开局已收容，不为展示商场美术擅改进度；仅开发模式提供不访问存档的明确美术预览。

2026-10-23后续用户要求“卡牌有时用不出来、对应收容物与对应装备战斗尽量20s内”，覆盖补丁原60–120秒低阶目标。20秒按1×模拟时间、包括进场接近计算；基准为满状态三人、一份对应阶级专属武器/防具＋两训练装备，抓捕使用前置已解锁装备。配置及逐局证据见 `GAMEPLAY_V03_BALANCE.json`；实机与修复见 `GAMEPLAY_V03_CARD_BALANCE_FIX.md`。

2026-10-23 用户明确要求按 `wanggeng_gameplay_patch_v0_3/wanggeng_patch_v0_3` 继续开发。冲突处以该新补丁为准，原文副本在 `gameplay-v0.3/`。

- 默认循环改为稳定放置产能→玩家确认手动失效→三人自动战斗＋九张共享武器卡→升阶→抓捕新对象；绝不自动失效。
- 旧三日指标与五主管技能不控制新版主线。经典模式仍独立保留，原第一日四人不变。新版三人出战，迁移多余员工不删除。
- 武器仍提供基础伤害，功能由其归属卡执行；五专属各三卡＋训练三卡。开场3、手牌4、每5模拟秒抽牌、成功结算后公共冷却2.5秒，暂停只有一个预备槽。
- 收容/装备阶级I–III，胜利解锁上限，装备面板显式升级；数值是配置初稿，未宣称全组合平衡。
- 稳定离线收益上限2小时，主动暂停无收益；战斗刷新/退出按放弃且无离线收益。旧档先备份、原键不覆盖，损坏档不强制覆盖。
- 保留现有二维设施、实体与美术；原型战斗场景是可替换的真实实体场景，卡牌列表不代替战斗。

下表为v0.2历史边界，仅在不与上面补丁冲突时沿用。当前实现/实测与未验证项见 [v0.3验收](GAMEPLAY_V03_ACCEPTANCE.md)。
