# 美术替换与兼容边界

## 本轮顺序

1. 员工拆件：大头小身、前倾姿态、六种发型、制服与武器；待机、走路、攀爬、三类作业、出手、受伤、恐慌、重伤倒地。
2. 环境模块：收容室、控制区、医疗区、走廊及竖向通路；五大厅继续采用原真实地图，设备和照明统一到低饱和墨线语言。
3. 五物：分别实现平静、工作反应、出逃、前摇、命中和受控表现，奶龙主样本与分身仍是实际独立实体。
4. 界面：顶栏、员工卡、真实危险提示、技能栏和档案模板；保留原DOM操作入口与面板布局。
5. 特效：受击墨迹、恐慌涂线、失效边缘撕裂、工作反馈及选择路径。
6. 复核：类型检查、原测试、构建、真实浏览器截图和连续操作记录；检查暂停、1280布局与场内命令。

## 资源组织

```text
src/art/
  ink.ts                       # 色板和确定性墨线工具
  effects.ts                   # 状态驱动的墨迹/恐慌/失效效果
  characters/abnormalities.ts   # 五物的平静/工作/失控拆件
src/scenes/facility/
  actors.ts                    # 员工、装备及五物绘制入口
  architecture.ts              # 房间/走廊/设备模块
  geometry.ts                  # 原地图映射及分区饰色
public/art/
  asset_mapping.json           # 旧资源标识到新表现的登记
  ui/                          # 原创SVG终端标识及图标
```

采用工程当前的Phaser结构，不创建无消费者的Unity目录或Editor脚本。2026-10-21已按需求表接入位图：288个PNG单元、206项运行素材、82项制作参考，缺失0。原图在`art-production/generated/`，实际加载PNG在`public/art/generated/`，运行时骨架在`src/art/generated/`。脚底、关节和握柄挂点绑定原真实实体，透明边裁切和缩放均留记录；具体交付与验证见`art-production/README.md`和`docs/GENERATED_ART_ACCEPTANCE.md`。上列程序模块保留作精确覆盖层及旧入口回归。

## 不改变的契约

八份现有配置、固定模拟步长、地图/工作位/脚底坐标、移动速度、四伤害、装备数值、技能、三日与存档契约保留。受伤的弯腰/步幅表现不修改真实移速。实际危险范围外边界不能为了手绘感任意偏移。

指南中的`dead`映射到现有`INCAPACITATED`重伤倒地：本日离场，下一日恢复，重伤本身不删除装备。重试恢复日初人员和装备快照，撤销当日购买与分配。不会增加永久死亡。`meltdown`只映射现有压力危险的橙红警报，不新增熔毁机制。残影只属于当前实体的美术，不创建额外敌人或伤害来源。

## 验收
