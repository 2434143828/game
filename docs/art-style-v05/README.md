# 网梗收容 · v0.5 美术风格改造包

## 文件内容

- `网梗收容_v0.5_美术风格一致性优化方案.md`：设计规范、当前问题、卡面/UI/设施/档案改造、参数与验收标准。
- `CODEX_执行任务.md`：给 Codex 的执行顺序与交付约束。
- `reference_screenshots/01_facility_current.png`：用户提供的设施当前截图。
- `reference_screenshots/02_archive_current.png`：用户提供的档案当前截图。
- `reference_screenshots/03_combat_current.png`：用户提供的战斗卡牌当前截图。

## 建议用法

将此目录的两个 Markdown 文件与 `reference_screenshots` 文件夹复制到现有仓库中（建议 `docs/art-style-v05/`），然后将 `CODEX_执行任务.md` 内容交给 Codex。

Codex 必须实际阅读现有仓库，并做增量改动；参考截图仅供对比，不要把截图当游戏可用素材。

建议先验收 **制式训练与 N01 奶龙三张卡 + 战斗 HUD**，确认画风一致后，才批量替换其余卡牌和界面。
