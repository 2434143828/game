## 执行顺序

**A. 基线（先做）**
- 定位实际 UI、Phaser 渲染层、卡牌数据/动画、收容档案和资产映射；列出“已实现 / 仅需调整 / 缺素材”。
- 执行现有测试并截图基线。不要猜测路径或覆盖现成资源。

**B. P0 卡牌统一（优先完成）**
- 建立共享的 E.G.O. 卡面模板（来源、类型、主图、卡名、所属员工、阶级、可用性）。
- 优先重绘/重组“制式训练”卡 + N01 奶龙 3 张卡；卡面统一为手绘图形化技能插画 + 机构模块框架，而非泛二游华丽插画。

- 特别注意：卡打出进入弃牌；**2.5 模拟秒是全队公共出牌冷却，不是单卡冷却**。所有动画受模拟暂停及 1×/2× 约束，出牌演出不更改真实伤害判定。

**C. P0 战斗 HUD**

- 至少实测 1280×720 和 1600×900，4 张手牌不卡字、不挡关键敌方目标，箭头坐标正确。

**D. P1 档案和设施**
- 保留档案左头像右信息，将右边平均卡片改成可阅读的“研究记录 / 失效须知 / 装备 / 产能与升阶”主次结构，不改权限和数值。
- 设施降低背景纹理抢眼，聚焦当前房间和角色，压缩底部多张大收容卡为轻量目录；所有点击和寻路功能必须保留。

**E. P1/P2 扩展及回归**
- 使用同一模板覆盖其余已实现 E.G.O. 来源；异常特效只局部出现，五张外勤场景保留现实场景，不得回退为实验室通用背景。
