# v0.4 P0 战斗统计

运行：

```powershell
npx vitest run tests/v04-combat-stats.test.ts
```

测试使用同一份 `V3Simulation` 和固定 seed，分别对 N01 主动失效（`BREACH_CHALLENGE`）与 N02 外勤抓捕（`CAPTURE`）跑三种策略：

- A：完全自动，不主动施放卡牌。
- B：从当前手牌随机选择合法目标并施牌。
- C：在敌人蓄力剩余 0.45 秒内优先控制/反击/格挡，其余时间优先伤害卡，并在精神值低时治疗。

结果写入 [`docs/v04-combat-stats.json`](./v04-combat-stats.json)。统计从固定步状态和事件日志读取，包含 encounter、seed、模拟/真实耗时、抽牌、施牌、打断、队伍 HP/SP 损失与剩余、自动攻击伤害、卡牌伤害、控制、护盾、治疗和胜负。

为使卡牌策略可比较，统计夹具将对应武器/防具装配到三名测试员工；正式的一份装备一名员工、解锁与奖励规则没有被修改。

当前基线结论：N01 三组均胜利（A 14.4s、B 16.5s、C 16.6s）；N02 三组均完成收容（A 7.8s、B 9.25s、C 8.2s）。C 组在 N02 产生了护盾与卡牌伤害并将队伍 HP 损失从 12 降到 9.6，但 N01 的 A 组没有受到 HP 伤害，C 组主要体现为 1 次打断和 31.5 卡牌伤害。战斗节奏仍低于补丁建议的 20–35/35–60 秒目标，当前记录作为待平衡基线，不把建议值误写成硬性通过条件。
